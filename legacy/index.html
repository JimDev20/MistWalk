How MistWalk works

01

Walk to reveal

Every point is snapped to a 12-metre tile. A tile unlocks only when a GPS fix inside it passes the walking gate. The fog lifts permanently; old tiles never return.

02

Walking only

The gate rejects fixes faster than about 10 km/h and locks out for 45 seconds when it detects a vehicle. The map only records what your feet earn.

03

Private by construction

No account, no server, no analytics. Your tiles, trail, and stats live in this browser's local storage with an IndexedDB mirror. Export a backup to move devices.

04

Free map first

OpenStreetMap tiles need no key, account, or billing. Google Maps is optional: paste a restricted browser key in settings. The free demo key needs no card, but Google's paid quotas can bill above the free allowance.

05

Using it on a phone

Browsers only give GPS to secure pages. On this computer, http://localhost is enough. For a phone, put this folder on any free static host with HTTPS, such as GitHub Pages, Netlify, or Cloudflare Pages, then open that link and install it to the home screen. No build step is needed.

Emergency backup

In Settings, choose Export backup to write one JSON file containing both the live and simulator profiles. Keep it somewhere safe; restoring replaces local progress.
